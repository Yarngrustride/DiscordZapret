> ### РЕАКЦИЯ АНТИВИРУСОВ
> Антивирус может среагировать на WinDivert.  
> Для работы zapret требуется WinDivert — средство перехвата и фильтрации сетевого трафика.
> Его применяют как безопасные, так и вредоносные программы, однако сам инструмент вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов классифицирует файлы WinDivert как инструменты для взлома или объекты повышенного риска, после чего удаляет их либо переносит в карантин. Название такого обнаружения обязательно содержит `WinDivert` или выглядит как `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Внесите папку с запретом в исключения антивируса или выключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky предусмотрен пункт «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы умеете аккуратно настраивать исключения, лучше добавить исключение; если не уверены в своих действиях — отключите обнаружение PUA.

## ⚙️Порядок использования

1. Настройте Безопасный DNS (Secure DNS)
    * В Chrome активируйте «Использовать безопасный DNS» и укажите поставщика DNS, выбрав не вариант «Поставщик по умолчанию»
    * В Firefox откройте «DNS через HTTPS», установите режим «Персональный», затем нажмите «Выбрать провайдера/поставщика» и вручную укажите URL. Подойдёт, например, `https://dns.google/dns-query`, поскольку Cloudflare может блокироваться
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — воспользуйтесь [этой инструкцией](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый способ
    * Владельцам роутеров Keenetic следует активировать параметр «Транзит запросов». Если его отключить, при настройке и работе Secure DNS на компьютере могут возникнуть проблемы

2. Откройте [страницу свежего релиза](https://github.com/Yarngrustride/zapret-discord-youtube/releases/latest) и загрузите архив zip/rar

3. В свойствах загруженного архива отметьте пункт «Разблокировать». При распаковке через 7-Zip или PeaZip выполнять этот шаг не требуется

4. Извлеките файлы в каталог, путь к которому не включает кириллицу и специальные символы

5. Откройте необходимый файл
    * Чтобы определить рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы добавить её в автозапуск: **`service.bat`** -> `Install Service` -> *Выберите подходящую стратегию*

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Этот способ подходит для проверки разных стратегий. Их работоспособность зависит от множества условий. **Перебирайте стратегии — ALT, FAKE и остальные, — пока не найдёте подходящий для себя вариант**

- [**`service.bat`**](./service.bat) — управление автозапуском и дополнительные возможности:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из списка служб
  - **`Check Status`** — просмотр состояния обхода и служб: стратегии в автозапуске и WinDivert
  - **`Game Filter`** — смена режима обхода для игр и прочих сервисов, работающих через UDP и TCP на портах выше 1023.  
  **После изменения режима перезапустите стратегию.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — выбор режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Эта функция пригодится при проверке ресурса, который открывается без zapret, но не работает с ним  
  В скобках показывается один из текущих статусов:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — проверяется присутствие IP-адреса в списке
    - `any` — фильтрация применяется к любому IP-адресу  
  - **`Auto-Update Check`** — включение или отключение автоматического поиска обновлений
  - **`Replace active fakes`** — замена выбранного активного фейка другим файлом из каталога `bin`
  - **`Update IPSet List`** — загрузка актуальной версии списка `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — ручной поиск обновлений
  - **`Run Diagnostics`** — поиск распространённых причин, мешающих работе zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`: это иногда помогает, если приложение внезапно перестало работать
  - **`Run Tests`** — открытие инструмента, проверяющего работоспособность стратегий:
    - `Standard tests` — тестирование сайтов, записанных в `utils/targets.txt`
    - `DPI checkers` — проверка DPI через различных провайдеров, включая Cloudflare, Amazon и других


## ☑️Частые вопросы и неполадки

### Скрипт `general*` запускается, но ничего не происходит

- При ручном запуске стратегии отдельным bat-файлом, а не через service, должен открыться winws.exe — окно обхода, видимое на панели задач.  
Если окно не появилось, обратитесь к [#522](https://github.com/Yarngrustride/zapret-discord-youtube/issues/522)

### Не удаётся подобрать рабочую стратегию
- Откройте командную строку с правами администратора
- По очереди выполните в консоли следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- После этого перезагрузите компьютер

### Не открывается веб-версия Telegram
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из запустившегося Блокнота
  - В появившейся папке найдите `hosts` и откройте его текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` либо замените прежний аналогичный блок
  - Сохраните изменения и снова проверьте соединение. Если результата нет, удостоверьтесь, что файл `hosts` действительно был сохранён.

#### Результат не гарантирован. Если способ не сработал, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и используйте [локальный прокси](https://github.com/Yarngrustride/tg-ws-proxy) либо любой публичный.

### Обход прекратил работать или не запускался изначально

> [!IMPORTANT]
> **Любая стратегия со временем способна утратить работоспособность.**
> Выбранный вариант может некоторое время работать, а затем перестать из-за обнаружения.
> В этом репозитории собрано много способов обхода. Когда не помогает ни один, создайте собственную стратегию: возьмите одну из имеющихся за основу и скорректируйте параметры.
> Описание параметров стратегий доступно [по этой ссылке](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и убедитесь в отсутствии ошибок

- Проверьте, внесён ли адрес нужного ресурса в доменные списки или перечни IP

- Переключитесь на другие стратегии, включая **`ALT`**, **`FAKE`** и остальные

- Выполните полную переустановку по инструкции из следующего раздела

- Дополнительная информация приведена в [#765](https://github.com/Yarngrustride/zapret-discord-youtube/issues/765)

### Как начисто обновить или переустановить программу?
- Сначала сохраните все ресурсы и данные, добавленные вами вручную
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`, исправьте найденные ошибки и в конце нажмите Y
- Удалите каталог с запретом
- Загрузите свежую сборку `zapret-discord-youtube-...` [со страницы релизов](https://github.com/Yarngrustride/zapret-discord-youtube/releases)
- Щёлкните архив правой кнопкой мыши и откройте свойства. Если справа внизу доступен пункт «Разблокировать», отметьте его, нажмите «Применить», затем «ОК»
- Распакуйте архив в новый каталог в корне диска, избегая пробелов и специальных символов в пути
- Поочерёдно запускайте разные скрипты `general` — стратегии — и проверяйте доступ к интернет-ресурсам. Если они недоступны, завершайте программу через значок замка на панели задач и переходите к следующей стратегии
- Найдя рабочий вариант, добавьте его в автозапуск: `service.bat` -> `Install Service` -> выберите нужную стратегию

### При включённом запрете перестаёт работать игра или приложение

- Удостоверьтесь, что в service.bat для `Game Filter` установлено **`disabled`**, а для `IPSet Filter` — **`none`**. Другие значения могут неожиданно повлиять на доступность ресурсов.

### Античит обнаруживает WinDivert

- Следуйте инструкции по адресу https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 запрашивает цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert остаётся в системе

1. В командной строке Windows, открытой через Win+R и `cmd`, определите имя службы следующей командой:

```cmd
driverquery | find "Divert"
```

2. Затем остановите службу и удалите её командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, выполнена ли настройка [Secure DNS](#%EF%B8%8Fиспользование)
- Выключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если ранее всё работало.
- Дополнительные советы есть в [#251](https://github.com/Yarngrustride/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Удостоверьтесь, что [Secure DNS](#%EF%B8%8Fиспользование) уже настроен
- Сначала желательно определить стратегию, с которой загружается YouTube, и запустить именно её.
- Откройте `service.bat` -> `Run Diagnostics`, затем очистите кэш Discord.
- Запустите приложение Discord и проверьте, помогло ли удаление кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею.
- Когда Discord недоступен даже в браузере, снова переберите все стратегии. Иногда YouTube работает с определённой стратегией, а Discord — нет.
- Другие рекомендации смотрите в [#252](https://github.com/Yarngrustride/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь приложением [tg-ws-proxy](https://github.com/Yarngrustride/tg-ws-proxy)
- Другой вариант — бесплатные MTProto-прокси из интернета

### Игры остаются недоступны

Игр существует слишком много, поэтому проверить и исправить работу каждой невозможно.

Попробуйте наиболее универсальную последовательность действий:
- обновите ipset через `service.bat`, после чего активируйте `Game Filter`
- если результата нет, дополнительно попробуйте режим `ipset any`

Учтите: `ipset any` может нарушить доступ ко многим сайтам, поэтому не оставляйте этот режим включённым постоянно. Лучше определить все IP-адреса, задействованные игрой, и внести их в `ipset-all.txt`

Если эти действия тоже не помогли, откройте тему в разделе [Discussions](https://github.com/Yarngrustride/zapret-discord-youtube/discussions), а не в issues, и дождитесь советов других игроков.

## 🗒️Как добавить адреса других ресурсов

Для расширения списка обхода внесите адреса в соответствующие файлы:
- **`list-general-user.txt`** — домены; их поддомены будут учтены автоматически
- **`list-exclude-user.txt`** — исключаемые домены, например когда IP сети присутствует в `ipset-all.txt`, но отдельный домен из неё фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети
  - Файлы с именами **`*-user.txt`** будут созданы автоматически при первом открытии `zapret` или `service.bat`
